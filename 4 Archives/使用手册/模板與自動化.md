這個模板的主要特點是其自動化功能，它能幫助你在每個項目、領域或資源中快速建立顶层、子層和底部的筆記。總共有6個自動化組成兩個快捷方式：

**添加父級筆記**
1. 創建新項目
2. 創建新領域
3. 創建新資源

**添加子級筆記**
1. 創建新項目筆記
2. 創建新領域筆記
3. 創建新資源筆記

**添加父級** 應用於創建子層文件夾和總結筆記，而**添加子級** 用於在子層文件夾中創建個別筆記。

要使用這些自動化，請按下 `Ctrl + P`，然後選擇相應的快捷方式：`QuickAdd: 添加父級筆記` 或 `QuickAdd: 添加子級筆記`。你也可以在設置中自定義熱鍵。

### 使用方法
這裡有一些示例來說明如何使用這些自動化：

1. **創建新領域**
2. **在領域內創建筆記**
3. **創建新項目**
4. **在項目內創建筆記**

**注意：與項目相關的領域應該在創建項目之前創建。**

創建領域和資源的步驟類似，請參照為資源創建筆記時概述的步驟。

### 示例
#### 創建新領域
1. 打開命令面板，選擇 `QuickAdd: 添加父級筆記`
![[Example - Add Parent Notes.png]]
2. 选择 `🌳 添加領域`
![[Example - Add Area.png]]
3. 输入領域名稱（不按 Enter 空白）
![[Example - Input Area Name.png]]

#### 在領域內創建筆記
1. 打開命令面板，選擇 `QuickAdd: 添加子級筆記`
![[Example - Add Child Notes.png]]
2. 选择 `🌳 添加領域筆記`
![[Example - Add Area Note.png]]
3. 输入筆記名稱
![[Example - Input Area Note Name.png]]
4. 選擇對應的領域
![[Example - Select Area.png]]

#### 創建新項目
1. 打開命令面板，選擇 `QuickAdd: 添加父級筆記`
![[Example - Add Parent Notes.png]]
2. 选择 `🎯 添加項目`
![[Example - Add Project.png]]
3. 输入項目名稱
![[Example - Input Project Name.png]]
4. 選擇相關領域
![[Example - Select Area for Project.png]]

#### 在項目內創建筆記
1. 打開命令面板，選擇 `QuickAdd: 添加子級筆記`
![[Example - Add Child Notes.png]]
2. 选择 `🎯 添加項目筆記`
![[Example - Add Project Note.png]]
3. 输入筆記名稱
![[Example - Input Project Note Name.png]]
4. 選擇對應的項目
![[Example - Select Project for Project Note.png]]
